## 3. Environment (cloud container)

- **JDK 26 is required and is not in the image**, which ships Java 21. The environment's network policy allows Oracle's download host, and denies `api.adoptium.net`, `download.java.net`, `cdn.azul.com`, `corretto.aws` and `api.sdkman.io`.
- **Put this in the environment's Setup script** (cloud environment menu in the session title bar, then Edit). It downloads and checksum-verifies Oracle JDK 26, then makes it the default in login shells along with a UTF-8 locale:

  ```bash
  #!/bin/bash
  set -euo pipefail
  JDK=/opt/jdk-26
  if [ ! -x "$JDK/bin/java" ]; then
    url=https://download.oracle.com/java/26/latest/jdk-26_linux-x64_bin.tar.gz
    curl -fsSL -o /tmp/jdk-26.tar.gz "$url"
    echo "$(curl -fsSL "$url.sha256")  /tmp/jdk-26.tar.gz" | sha256sum -c -
    mkdir -p "$JDK" && tar -xzf /tmp/jdk-26.tar.gz -C "$JDK" --strip-components=1 && rm /tmp/jdk-26.tar.gz
  fi
  cat > /etc/profile.d/jdk26.sh <<'EOF'
  export JAVA_HOME=/opt/jdk-26
  export PATH="$JAVA_HOME/bin:$PATH"
  export LANG=C.UTF-8 LC_ALL=C.UTF-8
  EOF
  ```
- **Run Maven through a login shell:** `bash -lc 'cd <checkout> && ./mvnw -B test'`. Without `-l` you get Java 21 and the POSIX locale, and two `OccurrencePathTest` tests error on non-ASCII names.
- **Tests run as root here**, so the permission-based tests skip; 9 skips is the baseline, and 11 on #293's branch. Use `setpriv --inh-caps=-dac_override,-dac_read_search` to exercise them.
- **Worktrees** under `.claude/worktrees/` are gitignored and die with the container. Everything that matters is pushed.
