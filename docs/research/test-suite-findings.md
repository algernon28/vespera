# The test suite held to REVIEW.md: what a read of every test found

Research record for the wayfinder map [#677](https://github.com/algernon28/vespera/issues/677). Every finding here is a fact about a test as it stood at commit `416af3e`, labelled with the verdict of a second, independent check against the code. It is not a decision: each ticket of #677 re-checks its findings against main before acting on them, and the record of what is done is that ticket's.

## Scope and method

- **What was read.** Every `*Test.java` and `*IT.java` under `src/test/java`: 2,875 test methods in 585 files, in 28 batches of about 6,000 lines, each read in full beside the production code it exercises and the record it links.
- **The standards.** `REVIEW.md`'s seven, with six kinds of finding:
  - `cannot_fail`: a claim that holds whatever production does;
  - `weak_claim`: a claim that can fail but is far weaker than its name or its words;
  - `spec_gap`: a recorded rule no test holds;
  - `oracle_copies_production`: an expected value worked out by the production rule itself;
  - `redundant`: the same claim held twice, or a table written out case by case;
  - `misnamed_or_stale`: a number or word that the code no longer has.
- **The second check.** Each finding was given to a reader told to refute it. CONFIRMED stood as stated; PARTIAL stood with the correction noted under it; REFUTED findings, 45 of them, are left out.
- **Not here.** Twenty findings from a first, sampled pass, which the second pass was told not to report again, are in #677's tickets: among them ADR-020, ADR-079/081 and ADR-084 unpinned, `CensusInvocationTest`'s gate test, the copied `ProgressLines` and the per-key profile tests.
